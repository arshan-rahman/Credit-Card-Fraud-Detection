# Credit Card Fraud Detection

## Project Overview
A machine learning project that predicts whether a financial transaction may be fraudulent based on transaction features.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Gradio
- Google Colab

## Dataset
The project uses a harmonized fraud dataset containing transaction features, transaction types, source labels, and fraud labels.

## Project Workflow
1. Data cleaning and preprocessing
2. Exploratory data analysis
3. Training and testing data split
4. Machine learning model training
5. Model evaluation using precision, recall, F1-score, and a confusion matrix
6. Interactive prediction interface built with Gradio

## How to Run
1. Open the `.ipynb` notebook in Google Colab.
2. Upload the required dataset.
3. Run the notebook cells in order.
4. Launch the Gradio interface to test sample transactions.

## Important Note
This is an educational project. Predictions are estimates and should not be used to make real-world financial decisions.
